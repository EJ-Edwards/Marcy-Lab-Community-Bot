# NetNaval

# Documentation
Click here https://ej-edwards.github.io/NetNaval/ to view documentation how this works

Multiplayer games use private threads only; the bot will not fall back to a public
thread. Give the bot permission to create private threads, manage threads, and send
messages in threads. Players must DM the bot `!place <PIN> A1 B2 C3`; ship coordinates
and the board stay in that private conversation. Do not enter multiplayer ship
coordinates in the shared thread. Manage Messages permission lets the bot remove
accidental placement commands sent there, but is not required for normal play.
