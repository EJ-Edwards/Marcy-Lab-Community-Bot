# NetNaval

# Documentation
Click here https://ej-edwards.github.io/NetNaval/ to view documentation how this works

Multiplayer games use private threads only; the bot will not fall back to a public
thread. Give the bot permission to create private threads, manage threads, send
messages in threads, and manage messages. Ship boards are sent to each player's
DMs, and the `!place` message is deleted before the placement is accepted. Players
must allow DMs from server members to receive their board.
